# 部署指南

> 目标服务器：`10.100.60.56`，部署路径 `/home/xbio/agentPlat`
> 访问地址：`https://xbio.everprox.com:18080`

## 日常更新部署

代码更新后，在 WSL 终端执行三步：

```bash
# 1. 同步代码
rsync -avz --delete \
  --exclude='.venv' \
  --exclude='web/node_modules' \
  --exclude='.git' \
  --exclude='__pycache__' \
  --exclude='.cache' \
  --exclude='.ruff_cache' \
  --exclude='.zcode' \
  --exclude='.playwright-mcp' \
  --exclude='web/dist' \
  --exclude='*.pyc' \
  --exclude='.env.local' \
  --exclude='docker/volumes' \
  --exclude='packages' \
  --exclude='aiDoc' \
  --exclude='agentPlat_backups' \
  /mnt/d/Yuxi/ xbio@10.100.60.56:/home/xbio/agentPlat/

# 2. 重建容器（用 prod 配置，不加载本地 override）
ssh xbio@10.100.60.56 "cd ~/agentPlat && docker compose -f docker-compose.prod.yml up -d --build"

# 3. 验证（等待约 30 秒后）
curl -s http://10.100.60.56:5050/api/health
```

> rsync 只传有变化的文件，通常几秒内完成。Docker 构建有层缓存，未改动的层会跳过。
> `--exclude='docker/volumes'` 避免覆盖服务器上的持久化数据。
> `--exclude='.env.local'` 保留本地开发配置不被同步。

### 仅改配置（不重建镜像）

如果只改了 `.env` 文件，不需要重新 build：

```bash
# 同步 .env
rsync -avz /mnt/d/Yuxi/.env xbio@10.100.60.56:/home/xbio/agentPlat/.env

# 重启容器即可生效
ssh xbio@10.100.60.56 "cd ~/agentPlat && docker compose -f docker-compose.prod.yml restart"
```

## 端口冲突处理

服务器上已有 rag-agent 等服务，Yuxi 的宿主机端口映射已调整避免冲突：

| Yuxi 容器 | 容器内端口 | 宿主机映射 | 说明 |
|---|---|---|---|
| api-dev | 5050 | 5050 | API 后端，对外访问 |
| web-dev | 5173 | 5173 | 前端开发服务器 |
| postgres | 5432 | **15432** | 避开 pgvector17 的 5432 |
| redis | 6379 | **16379** | 避开 valkey 的 6379 |
| paddlex-ocr | 8080 | **18080** | 避开 rag-nginx 的 8080 |
| milvus | 19530 | 19530 | 无冲突 |
| minio | 9000 | 9000 | 绑 127.0.0.1，无冲突 |
| neo4j | 7474/7687 | 7474/7687 | 绑 127.0.0.1，无冲突 |

> 容器之间通过 Docker 内部网络用容器名访问（`postgres:5432`、`redis:6379`），宿主机端口映射只用于外部调试，改端口不影响内部通信。

### 注意事项

- **修改 .env 后必须重启容器**：配置在启动时加载，热重载只对代码生效
- **热重载**：api-dev 和 web-dev 支持热重载，代码同步后自动更新，无需重建
- **worker-dev 不支持热重载**：改了 worker 相关代码需要 `docker compose restart worker-dev`
- **docker/volumes 目录不要同步**：包含 PG/Milvus/MinIO 等持久化数据，覆盖会丢数据
- **首次启动较慢**：Milvus 和 Neo4j 初始化需要时间，约 1-2 分钟
